# KCU 일정 가져오기 (개발판)

학교의 공식 확장 프로그램이 아닙니다. 별도 서버나 자체 회원가입 없이,
사용자가 학교 포털에서 조회한 ‘해야 할 일’의 일정 필드만 JSON으로 내보냅니다.
웹 학사일정은 확장이나 앱 없이도 열 수 있습니다. 개인 학사정보를 가져오는 기기에서만 확장을 사용합니다.

## 로컬 설치와 사용

1. 저장소에서 `node scripts/build-extension.mjs`를 실행합니다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’로 이 `extension` 폴더를 선택합니다.
3. https://portal.koreacu.ac.kr/ko/dashboard 에서 학교 공식 로그인 절차를 마칩니다.
4. 포털을 새로고침하고 ‘해야 할 일’이 표시될 때까지 기다립니다.
5. 해당 포털 탭에서 확장 아이콘 → ‘일정 파일 만들기’ → ‘일정 파일 내려받기’를 누릅니다.
6. 학사일정 웹의 ‘학교 일정 가져오기’에서 파일을 선택하고 미리보기를 확인한 뒤 반영합니다.

스토어 배포 전 개발판입니다. 일정 파일에는 과목·과제·시험 정보가 있으므로 공개 저장소에 올리지 마세요.

## 접근 범위

- 호스트 권한은 학교 포털 한 곳에만 요청하고 `scripting`으로 선택된 포털 탭에서 일정을 읽습니다.
- 콘텐츠 스크립트는 `https://portal.koreacu.ac.kr/*`에서만 실행됩니다.
- 포털이 원래 실행하는 두 요청(`GET /api/widgets/todoList`, 포털 재조회 응답)의 성공 JSON만 복제합니다. 확장 자체가 학교 API를 호출하지 않습니다.
- `Authorization`, 쿠키, 비밀번호, 프로필·학번을 수집하거나 저장하지 않습니다.
- 원본 응답은 보관하지 않습니다. 공통 모듈의 허용 필드만 남겨 해당 탭 메모리에서 유지합니다.
- 새로운 일정 요청이 시작되면 이전 응답을 지웁니다. 로그인 만료·형식 오류 시 이전 계정 데이터를 내보내지 않습니다.
- 외부 서버 전송, 원격 코드, 상시 갱신, 다른 탭 조회, 브라우저 기록 조회가 없습니다.
- 팝업은 사용자가 선택한 학교 탭의 가공된 일정만 읽습니다. 파일 다운로드는 사용자가 직접 누릅니다.

## 개발

`capture.js`와 `core/school-schedule.js`는 생성물입니다. 원본은 각각
`capture-source.js`, `../docs/core/school-schedule.js`이며 빌드 후 함께 커밋합니다.

검증 범위: 격리 Chromium에서 실제 MV3 로드, 포털 모의 응답 캡처, 팝업 내보내기,
401 이후 이전 데이터 제거. 실제 학교 로그인 세션에서 확장을 설치한 통합 검증은 별도입니다.
