고려사이버대학교 학사일정 캘린더 구독

학교 홈페이지에 공개된 학사일정을 매일 자동으로 가져와 구글 캘린더 · 애플 캘린더 · 아웃룩에서 바로 구독할 수 있는 표준 iCalendar(.ics) 피드로 제공합니다. 한 번만 등록하면 이후 일정이 바뀌어도 자동으로 반영됩니다.

구독 URL https://kcu-hub.github.io/kcu-schedule/kcu-schedule.ics

등록 방법

  • 구글 캘린더: 설정 → 캘린더 추가 → URL로 추가 → 위 주소 붙여넣기
  • 애플 캘린더(iPhone/Mac): 설정(또는 파일) → 캘린더 구독 → 위 주소 붙여넣기
  • 아웃룩: 캘린더 추가 → 인터넷에서 구독 → 위 주소 붙여넣기

안내

이 페이지는 재학생이 개인적으로 만든 비공식 도구이며 고려사이버대학교와 관계가 없습니다. 데이터는 학교 홈페이지 학사일정 페이지가 사용하는 공개 정보를 그대로 옮긴 것이며, 실제 학사일정은 항상 학교 공식 홈페이지가 기준입니다.
