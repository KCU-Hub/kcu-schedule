다가오는 일정

    이 페이지는 재학생이 개인적으로 만든 비공식 도구이며 고려사이버대학교와 관계가 없습니다. 실제 학사일정은 항상 학교 공식 홈페이지가 기준입니다. 데이터는 매주 자동 갱신됩니다 · 소스코드(GitHub)

    캘린더 구독

    https://kcu-hub.github.io/kcu-schedule/kcu-schedule.ics

    가장 확실한 방법 (안드로이드 포함 모든 기기)

    PC 브라우저에서 calendar.google.com 접속 → 왼쪽 "다른 캘린더" 옆 + 버튼 → "URL로 추가" → 위 URL 붙여넣기.

    안드로이드 구글 캘린더 앱에는 URL 추가 기능이 없어서, 이렇게 웹에서 한 번 추가해두면 같은 구글 계정으로 로그인된 폰 앱에 자동으로 동기화됩니다.

    아이폰 · 아이패드 · 맥 (Apple 캘린더)

    설정 앱 → 캘린더 → 계정 → 계정 추가 → 기타 → 구독 캘린더 추가 → 위 URL 입력. (Mac은 캘린더 앱 → 파일 → 새로운 캘린더 구독)

    윈도우 · 아웃룩

    Outlook(웹 또는 앱) → 캘린더 추가 → "인터넷에서 구독" → 위 URL 입력.
